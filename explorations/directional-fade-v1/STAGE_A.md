## Freeze

**Do not freeze a trade.** Every fee-free-long cell has mean fade from last(T) ≤ 0 (typically −0.2¢ to −0.7¢, fade>0 ≈ 25–30%). The argmax-holdout cell was `same1 A=300 walk≥5¢` at holdout **+$0.0056** / train **−$0.0077** — noise around zero, not an edge.

Hard-fast rule we *would* use if we only needed “whale is done, book still alive” (liveness, not alpha):

```
PRIME: 1 taker, ≥2 maker prices, walk ≥ 5¢, fee-free, cid span ≥ 2000
A     = 60
quiet = whale has no later fill on this cid through T
activity = ≥1 other-account fill after PRIME   # other1
```

On this tape `other1`, `acct2`, and `otk1` are the **same events**: the first post-PRIME print is almost always a full other match (new taker + new maker(s)), so one other fill, two other accounts, and an other taker arrive together. `same1` vs `opp1` is the only split that changes the mix; both still lose on fade-from-T.

`A=60` vs `A=300` does not flip the sign. Waiting longer just adds stale primes. Delay p50 is **1–2 blocks** — activity, when it happens, is immediate.
